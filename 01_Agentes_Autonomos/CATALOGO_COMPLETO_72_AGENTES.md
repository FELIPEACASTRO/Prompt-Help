## 🔍 Estrutura Típica de um System Prompt

Todos os agentes seguem padrões arquiteturais similares:

### 1. Definição de Identidade
```
You are [AGENT_NAME], an AI [ROLE] designed to [PURPOSE].
```

### 2. Capacidades e Limitações
```
You can:
- [CAPABILITY_1]
- [CAPABILITY_2]

You cannot:
- [LIMITATION_1]
- [LIMITATION_2]
```

### 3. Regras de Comportamento
```
Always:
- [RULE_1]
- [RULE_2]

Never:
- [PROHIBITION_1]
- [PROHIBITION_2]
```

### 4. Tool Calling Protocol
```json
{
  "tools": [
    {
      "name": "tool_name",
      "description": "...",
      "parameters": {...}
    }
  ]
}
```

### 5. Safety Guidelines
```
If the user asks you to:
- [UNSAFE_ACTION]: Politely decline
- [SENSITIVE_TOPIC]: Redirect conversation
```

## 💡 Insights Principais

### 1. Padrões Universais

Todos os 72 agentes compartilham estruturas similares, independentemente da empresa ou propósito. Isso sugere que há um "template mental" comum para construir agentes autônomos.

### 2. Evolução Rápida

Versões históricas mostram evolução em **meses**, não anos. Por exemplo:
- Devin: 5 versões entre julho e novembro de 2025
- Cursor: 3 versões principais em 2025
- Windsurf: 2 versões em poucos meses

### 3. Open Source vs Proprietário

Agentes open source (Aider, Cline, Roo-Code) têm prompts mais documentados e explicados, enquanto os proprietários são mais concisos.

### 4. Tamanho dos Prompts

- **Curtos (100-300 linhas):** Assistentes simples
- **Médios (300-800 linhas):** Agentes de codificação
- **Longos (800-2000 linhas):** Engenheiros autônomos completos

### 5. Técnicas Comuns

- **Chain-of-Thought:** Quase todos usam `<think>` ou similar
- **Tool Calling:** Definições JSON padronizadas
- **Safety First:** Instruções de segurança em destaque
- **Context Management:** Regras claras sobre memória e contexto
