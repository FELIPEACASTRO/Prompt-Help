# Prompts de Automação

Estes prompts são focados em automatizar tarefas repetitivas, gerar respostas padronizadas e otimizar fluxos de trabalho.

## 1. Automação de Comunicação

| Objetivo | Prompt Sugerido |
| :--- | :--- |
| **Respostas Padrão (FAQ)** | "Crie 5 respostas padrão e profissionais para as seguintes perguntas frequentes sobre o nosso [produto/serviço]: [Lista de perguntas]." |
| **E-mail de Follow-up** | "Elabore um modelo de e-mail de follow-up persuasivo e conciso para um cliente que demonstrou interesse em [tópico], mas não respondeu ao último contato. O tom deve ser [tom, ex: amigável e profissional]." |
| **Geração de Conteúdo para Redes Sociais** | "Gere 10 ideias de posts para [rede social, ex: LinkedIn] sobre o tema [tema]. Para cada ideia, forneça a legenda e 3 hashtags relevantes." |
| **Criação de Newsletter** | "Escreva o rascunho de uma newsletter semanal para [público-alvo] com o objetivo de [objetivo, ex: promover novos recursos]. Inclua uma seção de 'Dica da Semana' e um Call-to-Action claro para [ação]." |

## 2. Automação de Fluxos de Trabalho e Relatórios

| Objetivo | Prompt Sugerido |
| :--- | :--- |
| **Criação de Relatório Executivo** | "Atue como um Analista de Negócios Sênior. Com base nos seguintes dados de performance [insira dados ou resumo], gere um relatório executivo de uma página que inclua: 1. Sumário Executivo, 2. Principais Descobertas (3-5 pontos), 3. Recomendações Estratégicas (3-5 ações)." |
| **Otimização de Processos** | "Analise o seguinte fluxo de trabalho [descreva o fluxo de trabalho, ex: processo de onboarding de novos clientes]. Identifique 3 gargalos e sugira como a automação (usando [ferramenta, ex: Zapier, Power Automate]) pode otimizar cada etapa, reduzindo o tempo em [porcentagem]." |
| **Geração de Scripts de Automação** | "Escreva um script em [linguagem, ex: Python] que automatize a tarefa de [descreva a tarefa, ex: baixar todos os anexos de e-mails com o assunto 'Fatura' e salvá-los em uma pasta específica]. Inclua comentários explicativos." |
| **Criação de Diagrama de Fluxo** | "Gere o código [linguagem de diagrama, ex: Mermaid, PlantUML] para um diagrama de fluxo que represente o processo de [processo, ex: aprovação de despesas], começando com a submissão e terminando com o pagamento." |

## 3. Prompts de Automação de Código

| Objetivo | Prompt Sugerido |
| :--- | :--- |
| **Modernização de Código** | "Modernize o seguinte trecho de código [linguagem, ex: JavaScript ES5] para [linguagem/versão, ex: JavaScript ES6], focando em [conceito, ex: arrow functions e `const`/`let`]. [Insira o código]." |
| **Geração de Testes Unitários** | "Atue como um Engenheiro de QA. Escreva testes unitários (usando [framework, ex: Jest, Pytest]) para a seguinte função em [linguagem]: [Insira a função]. Garanta 100% de cobertura de *branches*." |
| **Documentação de API** | "Gere a documentação completa (formato [formato, ex: OpenAPI/Swagger]) para a seguinte rota de API em [linguagem/framework, ex: Node.js/Express]: [Insira o código da rota]. Inclua exemplos de requisição e resposta." |
| **Redução de Débito Técnico** | "Analise o seguinte código em [linguagem] e identifique 3 áreas de débito técnico (code smells). Para cada área, sugira uma refatoração e forneça o código refatorado. [Insira o código]." |
