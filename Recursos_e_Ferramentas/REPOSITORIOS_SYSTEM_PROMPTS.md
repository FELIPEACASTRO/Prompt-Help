## 🚀 Como Começar

### 1. Clone o Repositório Desejado

**EliFuzz (recomendado):**
```bash
git clone https://github.com/EliFuzz/awesome-system-prompts.git
cd awesome-system-prompts/leaks
```

**x1xhlol (mais popular):**
```bash
git clone https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools.git
cd system-prompts-and-models-of-ai-tools
```

### 2. Explore a Estrutura

```bash
ls -la
```

### 3. Acesse um Agente Específico

**Exemplo: Devin**
```bash
cd devin
cat prompt.txt
```

### 4. Compare Versões (EliFuzz)

```bash
cd devin/archived
ls -la
```

## 💡 Dicas de Uso

### 1. Compare Múltiplos Repositórios

O mesmo agente pode ter versões diferentes em repositórios diferentes. Compare para ver evolução.

### 2. Leia os Arquivos README

Cada repositório tem contexto importante no README.

### 3. Verifique Datas

System prompts evoluem rapidamente. Verifique as datas dos commits.

### 4. Use Git Blame

Para ver quando cada linha foi adicionada:
```bash
git blame arquivo.txt
```

### 5. Busque Padrões

Identifique estruturas comuns entre diferentes agentes.

## ⚠️ Avisos Importantes

### Sobre Legalidade

Estes prompts foram **vazados**, não oficialmente liberados. Use para estudo e pesquisa, respeitando os termos de serviço de cada plataforma.

### Sobre Atualidade

Repositórios são atualizados constantemente. Verifique a data do último commit.

### Sobre Completude

Nenhum repositório é 100% completo. Novos agentes surgem constantemente.

### Sobre Idioma

100% dos system prompts de agentes autônomos estão em inglês. Repositórios em português contêm apenas prompts gerais de ChatGPT.
